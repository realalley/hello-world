## 项目结构

```
.
├── index.html    # 网站主页
└── README.md     # 部署说明
```

## 部署到阿里云 ESA Pages

### 方式一：通过 GitHub 仓库导入（推荐）

1. **创建 GitHub 仓库**
   - 登录 GitHub，创建一个新的公开仓库（如 `hello-world`）
   - 将本项目的 `index.html` 上传到仓库根目录

2. **开通 ESA Pages 服务**
   - 登录 [阿里云 ESA 控制台](https://esa.console.aliyun.com/)
   - 在左侧导航栏选择「边缘计算和 AI」>「函数和Pages」
   - 首次使用需要开通服务（免费版即可）

3. **导入 GitHub 仓库**
   - 点击「创建」按钮
   - 选择「导入 GitHub 仓库」
   - 点击「添加 GitHub 账号」完成授权
   - 选择你刚创建的仓库
   - 填写项目名称

4. **配置构建设置**
   - 构建命令：留空（纯静态网站无需构建）
   - 输出目录：`/` 或留空
   - 框架预设：选择「静态」或「其他」

5. **开始部署**
   - 点击「开始部署」
   - 等待 1-2 分钟构建完成
   - 部署成功后会获得一个 `*.alibabacloud-esa.com` 的公网域名

### 方式二：使用模板创建

1. 登录 ESA 控制台，进入「函数和Pages」
2. 点击「创建」，选择「Pages模板」页签
3. 选择「静态网站」或「HTML」模板
4. 按照向导完成创建
5. 在代码编辑中替换为你的 `index.html` 内容

## 绑定自定义域名（可选）

部署成功后，可以在 ESA Pages 的「设置」>「域名」中添加自定义域名：
- 添加你的域名（如 `www.example.com`）
- 按照提示在 DNS 解析中添加 CNAME 记录
- 注意：绑定国内节点需要完成 ICP 备案

## 缓存配置建议

对于纯静态网站，推荐以下缓存策略：
- HTML 文件：缓存 1 小时
- CSS/JS 文件：缓存 7 天
- 图片等静态资源：缓存 30 天

可在 ESA 控制台的「缓存」>「缓存规则」中配置。
